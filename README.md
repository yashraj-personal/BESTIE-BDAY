## 🚀 Run Locally

### 1. Clone the repository

```bash
git clone https://github.com/hackncode1020/bestie-birthday.git
```

### 2. Open the project

```bash
cd bestie-birthday
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

Open the local URL shown in your terminal.

---

## 🤖 Gemini API Setup

If you want to enable the optional AI Birthday Studio:

### Create `.env.local`

```env
GEMINI_API_KEY=your_gemini_api_key_here
```

Then restart the development server.

### ⚠️ Important

**Never upload your real API key to GitHub.**

Keep secret keys inside `.env.local` and make sure they are ignored by Git.
